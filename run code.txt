HOW TO RUN:

--------------------------------------------------------------------------------
TERMINAL 1 — FastAPI Backend (ML + Live Ingestion + Alert Gateway)
--------------------------------------------------------------------------------
cd "c:\Users\jainv\Downloads\CycloneSense-main\CycloneSense-main\backend\fastapi"
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

  → API:          http://localhost:8000
  → Swagger docs: http://localhost:8000/docs

  On startup the app will:
    ✓ Connect to Redis (falls back to in-process LRU if Redis is not running)
    ✓ Load ML models (module1–module4)
    ✓ Start APScheduler: IMD + JTWC poll every 15 min, Satellite every 30 min
    ✓ Run first data fetch immediately

--------------------------------------------------------------------------------
TERMINAL 2 — React Frontend
--------------------------------------------------------------------------------
cd "c:\Users\jainv\Downloads\CycloneSense-main\CycloneSense-main\frontend"
npm run dev

  → Dashboard:    http://localhost:5173

--------------------------------------------------------------------------------
TERMINAL 3 — Spring Backend (optional — alert dispatch relay)
--------------------------------------------------------------------------------
cd "c:\Users\jainv\Downloads\CycloneSense-main\CycloneSense-main\backend\spring"
.\mvnw.cmd spring-boot:run

  → Spring API:   http://localhost:8080

--------------------------------------------------------------------------------
TERMINAL 4 — Redis (optional but recommended for full caching)
--------------------------------------------------------------------------------
  Windows:  winget install Redis.Redis  (first time only)
            redis-server

  Docker:   docker run -d -p 6379:6379 redis:7-alpine

  Without Redis the app works fine using the built-in in-process LRU cache.

================================================================================
KEY API ENDPOINTS (all prefixed /api/v1/)
================================================================================

  INGESTION
  GET  /ingestion/status          — Scheduler status + data freshness
  GET  /ingestion/live            — Full live IMD/JTWC/satellite snapshot
  POST /ingestion/refresh         — Manual on-demand refresh (?source=imd|jtwc|satellite|all)

  ALERTS
  GET  /alerts/languages          — 7 supported regional languages
  POST /alerts/multilingual       — Generate alert text for one district (all langs)
  POST /alerts/cap-xml            — Download CAP 1.2 XML alert document
  POST /alerts/dispatch           — Full dispatch: CAP + Twilio SMS + Webhook
  POST /alerts/fuzzy-ahp-risk     — Fuzzy-AHP risk scoring (Redis-cached 1 hr)
  POST /alerts/monte-carlo-damage — Monte Carlo P10/P50/P90 loss estimates (cached 30 min)
  GET  /alerts/cache-status       — Redis vs LRU cache stats

  ML PREDICTIONS
  POST /api/v1/predict-from-image-enhanced — Full pipeline from satellite image upload

================================================================================
SYSTEM CAPABILITIES
================================================================================
Module 1 (CNN/sklearn Pipeline)  — Storm intensity classification (knots, km/h)
Module 2 (GRU/LSTM Pipeline)     — Autoregressive 24-hr trajectory forecast
Module 3 (Fuzzy-AHP)             — Multi-criteria coastal risk scoring (Redis-cached)
Module 4 (Monte Carlo + GBM)     — P10/P50/P90 economic damage estimation (cached)
Module 5 (Alert Gateway)         — CAP 1.2 XML + Twilio SMS in 7 Indian languages:
                                   Hindi · Bengali · Telugu · Tamil · Odia · Gujarati · Marathi

LIVE PIPELINE
APScheduler                      — Polls IMD advisories every 15 min
                                 — Downloads JTWC ATCF best-track files every 15 min
                                 — Fetches INSAT-3D/GOES-17 IR satellite tiles every 30 min
Redis Cache                      — Fuzzy-AHP results cached 1 hour
                                 — Monte Carlo results cached 30 min
                                 — Ingestion payloads cached 15 min
                                 — LRU in-process fallback if Redis unavailable
